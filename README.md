# M1.QP4 - Interrupt-Based Sense-Think-Act System
Environmental monitoring system simulating temperature, door, and window sensors using external interrupt, pin change interrupt, and timer interrupt on Arduino Uno.

## Files
- TaskM1.cpp - main Arduino source code
- circuit-diagram.png - TinkerCad circuit
- serial-monitor-log.png - system output log

## How to run
Open TaskM1.cpp in TinkerCad or Arduino IDE, upload to Arduino Uno, open Serial Monitor at 9600 baud.
